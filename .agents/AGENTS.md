# Project Rules

- **Changelog Updates**: Always update the `CHANGELOG.md` file whenever making code changes, bug fixes, or adding new features. Ensure the updates are appended to the *end* of the appropriate section's list (e.g., Added, Fixed, Changed) under the `[Unreleased]` header. **Exception:** Do not add entries for purely internal maintenance such as internal refactors or test suite modifications unless they impact end-users.
